# KIN Releases

This repository is intentionally release-only. It does **not** contain the KIN application source code, backend implementation, credentials, or private project files.

For Android, download the APK attached to the latest GitHub Release. Android may ask you to allow installation from your browser or file manager.

Only install KIN packages published from this repository's Releases section.
